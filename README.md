# Python User Input

## Explanation

This program demonstrates how to take input from the user using Python's built-in `input()` function.

## Problem Statement

Write a Python program that accepts a user's name, age, and city and displays the entered information.

## Features

* Accepts user input
* Uses the `input()` function
* Demonstrates string input
* Converts age into an integer
* Displays the entered information

## How It Works

The `input()` function reads data entered by the user.

By default, `input()` returns the entered value as a string.

The `int()` function is used to convert the age from a string into an integer.

## Technologies Used

* Python 3

## Program Flow

1. Ask the user to enter their name.
2. Ask for their age.
3. Ask for their city.
4. Convert the age into an integer.
5. Display all the entered information.

## Sample Input

```text id="f7k3q2"

```

City: Hyderabad
